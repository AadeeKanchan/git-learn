# Git Learn

A minimal web project to learn Git and GitHub.

## 4 Commands to Know

```powershell
# 1. See changes
git status

# 2. Stage changes
git add .

# 3. Save snapshot
git commit -m "First commit"

# 4. Push to GitHub
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```
